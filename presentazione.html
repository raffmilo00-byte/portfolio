Scelte di design

  • Tema dark — palette scura (#0f1115) con accenti ciano e viola per leggibilità e modernità
  • Tipografia system-ui — font di sistema per performance e coerenza cross-device
  • Layout CSS Grid + Flexbox — nessun framework, tutto scritto a mano
  • Sticky header con backdrop-filter blur per effetto glassmorphism leggero
  • Menu hamburger mobile — navigazione ottimizzata per smartphone
  • Bottoni pill con gradiente accent per gerarchia visiva chiara

HTML5 semantico CSS3 Flexbox CSS Grid Media Query CSS Variables JavaScript (menu) Git GitHub Pages VS Code

Accessibilità

  • Skip link "Salta al contenuto"
  • Landmark HTML: header, main, footer, nav
  • Attributi aria-label e aria-expanded sul menu
  • Contrasto colori WCAG AA
  • Form con label associati correttamente
